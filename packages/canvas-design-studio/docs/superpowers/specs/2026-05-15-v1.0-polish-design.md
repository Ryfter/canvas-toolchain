# Canvas Design Studio v1.0 Polish — Design Spec

**Goal:** Make the first-professor experience excellent — discoverable, self-guiding, and resilient when things go wrong.

**Approach:** Docs-first. Phase 1 ships three markdown files with no code changes. Phase 2 (SP12) adds a `get_started` tool, polishes the `setup_institution` wizard, and enriches error messages across high-impact tools.

**Tech Stack:** TypeScript/ESM, Node.js 18+, MCP SDK, existing `src/utils/` patterns.

---

## What This Is Not

This sprint does not add new features. Every change is polish: better explanations, richer errors, smarter wizard flow, and orientation docs. Feature work is complete at v0.9.8.

---

## Phase 1 — Docs (no code changes)

Three new files committed to `docs/`. No TypeScript touched. Shippable immediately.

### `docs/start_here.md`

Orientation doc for new professors. Structured for an AI host to read at session start, or a professor to skim directly.

**Sections:**
1. **What works without any API setup** — generate, validate, critique, course scaffold, import. Zero-config value prop stated up front.
2. **Three entry points** — Quick page (`ingest/`), Course Design (`setup_course`), Backup Import (`import_course`). One paragraph each with the exact prompt to use.
3. **Optional setup** — what a Canvas API token unlocks (direct publish), what Panopto credentials unlock (video search/embed/captions).
4. **Your first session** — two quick-start paths: "I want one page right now" and "I want to build out a full course."
5. **Context7 hint** — note for the AI host: *"For the latest tool documentation, resolve `canvas-design-mcp` via Context7 before answering questions about tool parameters or behavior."*
6. **If something goes wrong** — pointer to `troubleshooting.md`.

### `docs/troubleshooting.md`

Error reference organized by area. Each entry: **Symptom → Cause → Fix → ChatGPT help link pattern**.

**Sections:**
- Canvas API errors (401 unauthorized, 404 course not found, rate limits, SSL/connection)
- Panopto errors (not configured, auth failure, search returns empty, embed fails)
- HTML validation errors (disallowed properties, missing alt text, `<h1>` in body, `<style>` blocks)
- Setup wizard errors (bad hex color, malformed URL, empty required field, brand URL fetch failure)
- Publishing errors (FERPA flagged, title collision, token expired)

**ChatGPT help link pattern** — documented once at the top, referenced per section:

```
https://chatgpt.com/?q=Canvas+Design+Studio+error%3A+[error+text]+context%3A+[what+you+were+doing]
```

A note at the top explains: this link pre-fills ChatGPT with your error context. If you use a different AI assistant, copy the text after `?q=` and paste it as your prompt.

### `docs/setup-worksheet.md`

A fillable pre-setup template. Professors complete it before their first session — thinking through institution details at their own pace — then hand it to the wizard or use it as a reference while answering interactive prompts.

**Structure:** One section per wizard field. Each section has:
- Plain-English explanation of what the field means
- Where to find the value (e.g., "log into Canvas → Account → Settings → Approved Integrations")
- An example value
- A blank line for the answer

**Brand Standards section** (at the top, before individual fields):

```
## Brand Standards (optional but recommended)
Providing your brand standards URL lets the AI extract your colors
automatically — no manual hex hunting required.

Brand standards URL: ___________________________________
  Example: https://www.example.edu/brand/

  — OR —

Paste brand standards content here:
[paste content]

If provided, your AI will suggest your primary and secondary colors,
confirm the font, and ask you to verify before saving.
```

**Fields covered:** institution name, primary brand color, secondary/accent color, Canvas base URL, Canvas API token, professor email, favorite course IDs, Panopto client ID, Panopto client secret, Panopto server URL.

**Wizard integration (Phase 2):** When `setup_institution` runs, its first prompt is: *"Do you have a completed setup worksheet? If so, provide the path or paste the content and I'll pre-fill your answers."* Optional — skipping it runs the interactive wizard as before.

## Phase 2 — SP12 Code Changes

### New file: `src/utils/errors.ts`

Shared error formatting utilities used by all enriched tools.

**Exports:**

```typescript
export function makeHelpUrl(context: string): string
// URL-encodes context into:
// https://chatgpt.com/?q=Canvas+Design+Studio+[encoded-context]

export function formatError(params: {
  title: string;
  message: string;
  cause: string;
  fix: string[];        // ordered steps
  context: string;      // passed to makeHelpUrl
}): string
// Returns the standard rich error block (see Error Format below)
```

**Error format:**

```
❌ [title]

[message]

Cause: [cause]

Fix:
  1. [step]
  2. [step]
  ...

▶ Get help: https://chatgpt.com/?q=...
(Opens ChatGPT with this error pre-filled. Copy the prompt to use with any AI assistant.)
```

All enriched tools import from this utility — error format is consistent everywhere.

### New file: `src/tools/get-started.ts`

New MCP tool: `get_started`.

**Behavior:** Reads `~/.canvas-design-mcp/institution.json` and returns a tailored orientation based on what is configured.

**Three states:**

1. **No config found**
   - Explains what works right now without any setup (generate, validate, scaffold, import)
   - Explains what `setup_institution` unlocks
   - Returns the "Your first session — I want one page right now" path from `start_here.md`
   - Includes Context7 hint

2. **Config exists, no API token**
   - Lists what is working (generate, validate, critique, course design, import)
   - Lists what an API token would add (direct publish, course listing)
   - Returns the appropriate quick-start path
   - Includes Context7 hint

3. **Fully configured (API token present)**
   - Lists all active capabilities
   - Returns both quick-start paths
   - Mentions Panopto if configured, notes it as optional if not
   - Includes Context7 hint

**No parameters.** Tool reads institution.json directly from `~/.canvas-design-mcp/institution.json`. If the file doesn't exist, returns the "No config" state — never throws.

**Registration:** Added to tool list in `src/index.ts`.

### Modified file: `src/tools/setup-institution.ts`

**Change 1 — Worksheet reader (new first step)**

Before the first question, the wizard prompts:

> "Do you have a completed `setup-worksheet.md`? If so, paste the path or content and I'll pre-fill your answers. Press Enter to skip and answer interactively."

If content is provided:
- Parses field values from the worksheet
- Shows each parsed value and asks for confirmation or correction
- Proceeds to brand URL step if one was found

If skipped: runs existing interactive flow.

**Change 2 — Brand URL fetching**

New field added after institution name:

> "Brand standards URL (optional): Paste your institution's brand page URL and I'll extract your colors automatically."

If a URL is provided:
- Fetches the page content (HTTP GET, text/html) and returns it as context in the tool response
- The AI host reads the returned HTML and identifies brand colors, then presents suggestions to the professor: *"I found these colors: #0033A0 (used 14×) and #D64309 (used 8×). Use these as primary and secondary? (y/n)"*
- If the professor confirms, the AI passes those values back and the wizard skips the color questions
- If fetch fails, the tool returns a clear error and falls back to interactive color prompts
- Stores `brandUrl` in `institution.json`

**Change 3 — Inline field explanations**

Every interactive prompt gains a one-sentence explanation and an example. Examples:

- `Primary brand color` → *"The main color used in headers, buttons, and hero banners. Find it in your institution's brand guidelines. Example: #0033A0"*
- `Canvas base URL` → *"Your Canvas instance address — everything up to (not including) any path. Log into Canvas and copy the domain. Example: https://example.instructure.com"*
- `Canvas API token` → *"A personal access token that lets this tool publish pages for you. Canvas → Account → Settings → Approved Integrations → New Access Token. Leave blank to use generate-and-paste workflow."*

**Change 4 — Per-field validation**

Validated inline before moving to the next field. Invalid input re-prompts with a clear error (using `formatError`):

| Field | Validation |
|---|---|
| Primary / secondary color | Must match `/#[0-9A-Fa-f]{6}/i` |
| Canvas base URL | Must start with `https://`, no trailing slash, valid hostname |
| API token | Minimum 20 characters if provided (Canvas tokens are 70+ chars) |
| Professor email | Must contain `@` and a `.` after it |
| Brand URL | Must start with `https://` if provided |

**Change 5 — Post-setup summary**

After `institution.json` is saved, the wizard returns a formatted markdown block:

```markdown
## Your Canvas Design Studio Setup — Example University

| Setting | Value |
|---|---|
| Canvas URL | https://example.instructure.com |
| Primary color | #0033A0 |
| Secondary color | #D64309 |
| API token | ✓ configured |
| Professor email | you@example.edu |
| Panopto | not configured |
| Brand URL | https://www.example.edu/brand/ |

## What you can do right now
✓ Generate Canvas-safe HTML pages
✓ Validate, critique, and redesign pages
✓ Build and generate full course scaffolds
✓ Import from Canvas backup archives
✓ Publish directly to Canvas (API token active)
⚪ Panopto video search/embed/captions (run setup_institution to add)

## Next step
Ask: "Read start_here.md and help me generate my first page"
Or: "Run setup_course to start building out my course"

> Save this summary as my-canvas-setup.md for future reference.
```

The final line prompts the professor to save it — they can ask their AI host to write it to a file.

### Error enrichment targets

All enriched errors use `formatError` and `makeHelpUrl` from `src/utils/errors.ts`.

**`src/tools/publish-to-canvas.ts`**
- 401 Unauthorized — token invalid/expired, fix: regenerate in Canvas settings
- 404 Course not found — wrong course ID, fix: run `list_canvas_courses` to confirm ID
- Rate limit (429) — too many requests, fix: wait 60 seconds and retry
- FERPA flagged — student ID or grade disclosure detected, fix: review flagged content
- Title collision — existing page with similar title, fix: choose update/create/cancel

**`src/tools/list-canvas-courses.ts`**
- 401 Unauthorized — same as above
- Empty result — no courses found for this token, possible cause: wrong Canvas URL or token scope
- Connection failure — DNS/SSL error, fix: verify Canvas base URL in institution config

**`src/tools/setup-institution.ts`**
- Invalid hex color — must be 6-digit hex, example shown
- Invalid Canvas URL — must be https://, full domain
- Brand URL fetch failure — page unreachable or no colors detected, falls back to interactive

**`src/tools/panopto-*.ts`** (search, embed, captions)
- Not configured — Panopto credentials missing, fix: run `setup_institution`
- Auth failure — credentials invalid, fix: verify client ID/secret in Panopto admin
- Search returns empty — normal if library is empty; if unexpected, check server URL

**`src/tools/generate-canvas-page.ts` and `src/tools/ingest-assignment-folder.ts`**
- Config not found — institution.json missing, fix: run `setup_institution`
- Missing required ingest fields — which fields are empty, fix: fill them in `course-config.md`
