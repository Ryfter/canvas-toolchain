# Other Canvas Design Tools

Parent: [Canvas Design Knowledge Base](../README.md)
Related: [Canvas Theme Editor](Canvas-Theme-Editor.md), [Canvas Built-In CSS Classes](../01-canvas-rce/Canvas-Built-In-CSS-Classes.md)

This page lists external tools and practitioner resources that are useful for understanding Canvas page design. They are references, not dependencies. Canvas Design Studio should keep generating portable Canvas-safe HTML that works without a paid add-on.

## Loree Design

[Loree Design](https://soaringed.com/loree-design/) is an LTI page builder for Canvas and other LMS platforms. It is useful as a comparison point for no-code page building, template libraries, and responsive layouts.

Canvas Design Studio does not depend on Loree. Use it only as a reference for what instructors expect from visual page-building workflows.

## HowToCanvas

[HowToCanvas](https://www.howtocanvas.com/create-amazing-pages-in-canvas) is a practitioner tutorial site with copyable Canvas HTML patterns.

Useful starting points:

| Tutorial | URL |
|---|---|
| Page separations and Canvas border classes | https://www.howtocanvas.com/create-amazing-pages-in-canvas/page-separations |
| Canvas Theme Editor CSS guide | https://www.howtocanvas.com/theme-editor/css-theme-editor |
| Accordion menus | https://www.howtocanvas.com/create-amazing-pages-in-canvas/accordions |
| Background and pattern effects | https://www.howtocanvas.com/create-amazing-pages-in-canvas/background-css |
| HTML image maps | https://www.howtocanvas.com/create-amazing-pages-in-canvas/html-image-map |
| Responsive YouTube iframes | https://www.howtocanvas.com/create-amazing-pages-in-canvas/responsive-youtube-iframes |

Key discovery from this site: Canvas ships with useful built-in classes such as `border`, `border-trbl`, `border-round`, `content-box`, `grid-row`, and `col-md-*`. See [Canvas Built-In CSS Classes](../01-canvas-rce/Canvas-Built-In-CSS-Classes.md).

## Fleximode Canvas Cheat Sheet

[Fleximode Canvas Cheat Sheet](https://fleximode.manukau.ac.nz/cheat-sheet-for-canvas/) is a concise HTML cheat sheet with copy-paste snippets. It is especially useful for responsive grid examples using Canvas built-in classes.

## Johns Hopkins Advanced Course Design Guide

[Advanced Course Design Options for Canvas](https://support.cmts.jhu.edu/hc/en-us/articles/7794555282445-Advanced-Course-Design-Options-for-Canvas) is an institutional guide covering Canvas HTML patterns such as accordions, blockquotes, button links, and HTML allowlist references.

## Canvas Commons

[Canvas Commons](https://community.instructure.com/en/kb/articles/660349-what-is-canvas-commons) is Canvas's built-in content sharing marketplace. Search for course templates, homepage examples, and module shells that can be imported into a course.

## Canvas LMS Source

[Canvas LMS on GitHub](https://github.com/instructure/canvas-lms) is useful for verifying sanitizer behavior and built-in class names directly from source.
