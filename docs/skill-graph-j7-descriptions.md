# J7 — skill-graph description rewrites

Review table for J7: the 31 operation descriptions that exceeded the
200-character skill-graph lint budget, rewritten to fit. Nothing else changed —
ids, input schemas, handlers, sections, and intent-tool wiring are untouched.

What the rewrites preserve, per row:

* every constraint, side effect, and prerequisite (writes a file, needs a token,
  needs an LLM, must follow another operation);
* every safety warning (publishes to Canvas, spends WAVE credits, deletes
  snapshots, is read-only);
* the distinguishing detail that makes selection correct — the "use this when,
  not that" clause (local draft vs live Canvas, authoring vs validation,
  attached rubric vs course list).

Generated from the pre-change registry text — the tree as of the commit before
the J7 rewrite, `git show f4dc411^:packages/command-and-control/skills/ops/<id>.md`
— and the rewritten registry. The regenerated tree
in `packages/command-and-control/skills/` is the post-change form; `new` is the
same string the op files and MOCs now carry.

`chars` is the length of `new`; the budget is 200.
